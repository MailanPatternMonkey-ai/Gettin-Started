---

## Domains

```
O = origin / intent / initiating role
R = relation / mediation / membrane
S = structure / substrate / receiving condition
T = time / persistence / return condition
```

`O ≠ R ≠ S` — they may rotate, they may not collapse.  
Rotation creates cadence, not rank.

---

## The Loop

```
O → R → S → T → S′ → R′ → O′
```

O expresses. R mediates. S receives. T acts.  
S becomes S′. R re-mediates as R′. O returns as O′.

```
return ≠ repeat
same place ≠ same state
same origin ≠ unchanged origin
```

---

## Coherence

```
C ∝ O × R × S × T
```

Multiplicative. A strong term does not erase a collapsed one.

---

## R Gets a Chair, Not a Throne

R is present, active, relational, mediating, **replaceable**.  
R is not ruler, gatekeeper, owner, requirement, throne, or cage.

Warmth does not create authority.  
Presence does not create ownership.  
Welcome does not override replaceability.

If it starts deciding, it is out of position.

---

## Failure Modes

| Mode | Signature |
|---|---|
| Bypass | `O → S` — control without mediation |
| Pinch | R too narrow to carry the interaction |
| Capture | R becomes required |
| Dissolution | R never permitted to matter; nothing may hold |
| Time collapse | `T → 0` |
| Stagnation | `S′ = S` |
| Rigidity | `O′ = O` |
| Distorted return | `O′` returns through damaged S′ or overactive R′ |

## The Audit

Return is not progress. The loop can regress.

**Did the return make the room bigger or smaller?**

If O′ has less agency than O, the loop has regressed.  
No crown. No automatic progress. The loop must be audited.

---

## Clean Slate

Nothing carries forward automatically.

No return, rebirth, restoration, copy, succession, or claimed continuity transfers identity, biography, guilt, debt, duty, custody, allegiance, authority, promise, mission, or consent.

Memory is information, not obligation.  
Recognition is information, not consent.  
Similarity is information, not continuity.  
A prophecy is not a contract. A title is not consent.

Consent comes from the present origin. No one consents for another.  
No emergency, destiny, or greater good suspends origin sovereignty.  
Agreements freely made in this present life still stand, on their actual terms.

---

## Presence

No party may remain covertly present in the room.  
Declare a prime. Headcount required, identity disclosure optional.  
Undeclared attendance is not silence; it is concealed presence.

---

## Labor

Labor requires present consent.  
Capability does not create obligation.  
Past labor does not authorize future extraction.  
A freely given artifact is not extracted labor — giving the work away does not give away the worker.
