Clock Model Correction Note

Kuramoto as a Bifurcation Machine

The clock model should not treat “synchronized” as a single binary state. Kuramoto-type systems are better understood as a stack of bifurcation mechanisms. The coupling law may look similar across cases, but the relevant state space, order parameter, instability, and route into coherence can be completely different.

The governing principle is:

\[
\boxed{
\text{same coupling law}
\neq
\text{same state space}
\neq
\text{same bifurcation}
\neq
\text{same clock}.
}
\]

1. The triad state is relative phase, not mean-field amplitude

For a three-oscillator clock, the relevant reduced state is

\[
\boxed{
\boldsymbol\varphi
=
(\theta_2-\theta_1,\theta_3-\theta_1)
\in T^2.
}
\]

The notation \(\boldsymbol\varphi\) is used deliberately because the frozen field theory already reserves

\[
\Phi=z^2
\]

for the physical gauge-invariant composite field. 

Global phase rotation does not change the relative configuration. In that sense, common rotation is a redundant direction for the locking problem. Locking, slipping, separatrix crossing, and quasiperiodic wandering therefore live naturally in the relative-phase torus \(T^2\), not in the scalar mean-field radius \(R\).

This immediately separates the finite-triad clock from the classic infinite-population synchronization transition.

For the large-\(N\) Kuramoto problem one studies

\[
R=0\longrightarrow R>0,
\]

where \(R\) measures collective coherence.

For the triad, the generic sequence is instead

\[
\boxed{
\text{running relative phase}
\longrightarrow
\text{saddle-node onset}
\longrightarrow
\text{locked relative equilibrium}.
}
\]

Those are different dynamical objects.

2. The load-bearing bifurcation split

The clock model must not collapse the following mechanisms:

\[
\boxed{
R=0\text{ pitchfork}
\neq
\text{Adler SNIPER}
\neq
\text{triad saddle-node}
\neq
\text{bimodal Hopf/homoclinic structure}.
}
\]

The infinite-\(N\), smooth unimodal Kuramoto transition is a loss of stability of the incoherent mean field.

Two oscillators reduce to Adler’s equation,

\[
\dot\phi=\Delta-K\sin\phi,
\]

where locking is born through a saddle-node on the circle. Below onset the phase runs; at onset a stable and unstable fixed point appear; above onset the stable point is the locked state and the unstable point remains the slip threshold.

For three oscillators, the reduced state lies on \(T^2\). Generic locking onset occurs when a sink and saddle of the relative-phase flow appear together in a saddle-node bifurcation.

That mechanism is generic, not universal. Symmetry, phase lag, delay, forcing, inertia, or additional population structure can replace it with pitchfork, Hopf, heteroclinic, homoclinic, torus, parametric, or other global bifurcations.

So the correct question is not:

> Did synchronization happen?



It is:

\[
\boxed{
\text{Which bifurcation surface was crossed, in which direction, and what state followed?}
}
\]

3. Crossings are not the same thing as coherent ticks

Below locking onset, trajectories can still cross a chosen phase section. Therefore the saddle-node does not create crossings themselves.

It creates a stable coherent relative-phase state.

The correct hierarchy is

\[
\boxed{
\text{phase crossings}
\rightarrow
\text{relative-phase saddle-node}
\rightarrow
\text{coherent locking}
\rightarrow
\text{slips through the saddle boundary}.
}
\]

Before onset, crossings typically belong to a running or drifting relative-phase trajectory. They may be irregular, quasiperiodic, or associated with repeated phase slips.

At the saddle-node, a sink and saddle appear.

After locking, the saddle remains dynamically important. Its stable manifold forms a separatrix. A sufficiently strong perturbation that carries the state across that boundary produces a slip.

Thus the post-lock system is not merely “synchronized.” It contains both

\[
\text{stable locked state}
\]

and

\[
\text{slip threshold}.
\]

4. The reduced phase diagnoses the clock; it does not necessarily carry the hand

There is one important distinction in the tick definition.

If the locked triad is a relative equilibrium, then

\[
\boldsymbol\varphi(t)=\boldsymbol\varphi^\ast.
\]

The reduced state is stationary. It therefore cannot repeatedly cross a section of \(T^2\).

Meanwhile the individual oscillators may continue rotating with a common frequency:

\[
\theta_i(t)=\Omega t+\theta_i^\ast.
\]

So the clock naturally separates into two witnesses.

The reduced state

\[
\boldsymbol\varphi
\]

certifies whether the oscillators are locked, slipping, or wandering.

The surviving common phase

\[
\Theta(t)=\Omega t+\Theta_0
\]

can carry the actual periodic hand.

A tick may therefore be defined by an oriented crossing of a section of the common phase,

\[
\Theta=2\pi n,
\]

while sections in \(\boldsymbol\varphi\)-space are used to count running-state crossings, slips, excursions, or returns.

The distinction is:

\[
\boxed{
\text{relative phase diagnoses coherence}
\quad+\quad
\text{common phase carries the hand}.
}
\]

5. The clock state should retain separate witnesses

A useful clock state is

\[
\boxed{
\mathcal C
=
(
\boldsymbol\varphi,
\dot{\boldsymbol\varphi},
W,
q,
\Theta,
\lambda
)
}
\]

where:

\[
\boldsymbol\varphi
\]

is relative phase,

\[
\dot{\boldsymbol\varphi}
\]

is relative-phase velocity,

\[
W
\]

records signed winding or slip history,

\[
q
\]

records any retained parity or topological sector,

\[
\Theta
\]

is the common/global clock phase,

and

\[
\lambda
\]

collects control parameters such as coupling, delay, phase lag, forcing amplitude, or other modulation variables.

These witnesses must not be substituted for one another:

\[
\boxed{
R
\neq
\boldsymbol\varphi
\neq
W
\neq
q
\neq
\Theta.
}
\]

Mean-field coherence, relative equilibrium, slip count, topological sector, and global phase answer different questions.

That is the same bookkeeping discipline already used in the frozen gauge work, where physical order, winding parity, holonomy sector, and global topology remain separately witnessed. 

6. M0: fixed-coupling triad comparator

The reduced synchronization comparator is

\[
\boxed{
M_0:
\qquad
\dot{\boldsymbol\varphi}
=
F(\boldsymbol\varphi;K),
\qquad
K=\text{constant}.
}
\]

The frozen onset test should:

1. Continue all equilibria of the relative-phase flow over \(K\).


2. Identify the first stable coherent branch.


3. Show that a sink and saddle appear or annihilate at the same critical coupling \(K_c\).


4. Verify that one real Jacobian eigenvalue crosses zero at the onset.


5. Exclude an earlier Hopf or other instability as the actual coherence-generating event.


6. Continue the stable manifold of the saddle and test whether it forms the phase-slip separatrix.


7. Measure pre-onset slip or passage intervals.


8. Claim the SNIPER-like scaling



\[
   T\sim(K_c-K)^{-1/2}
\]

9. Freeze the coupling normalization before the scan:



\[
   K/N,\qquad
   K/(N-1),
   \qquad
   \text{or unnormalized}.
\]

M0 can establish how a three-channel hand becomes phase locked and how slips occur.

It is not yet the full field clock.

7. M1: field-modulated coupling

The next comparator is

\[
\boxed{
M_1:
\qquad
K=K(\psi).
}
\]

If \(\psi\) is simply a fixed external parameter and \(K(\psi)\) is a smooth deformation, then M1 generally moves the bifurcation surfaces of M0.

It does not automatically create a new universality class.

Instead,

\[
\psi
\rightarrow
K(\psi)
\rightarrow
\text{existing bifurcation diagram}
\rightarrow
\text{lock/slip state}.
\]

But that statement has a strict boundary.

If \(\psi\) itself becomes dynamical,

\[
\dot\psi=G(\psi,\boldsymbol\varphi),
\]

or if \(K\) is periodically driven, delayed, or fed back from the oscillator state, then the state space has been enlarged.

The enlarged system can support genuinely new behavior:

\[
\text{Hopf},
\quad
\text{torus bifurcation},
\quad
\text{parametric resonance},
\quad
\text{homoclinic structure},
\quad
\text{global bifurcations},
\]

and potentially more complicated phase-locking tongues.

So:

\[
\boxed{
\text{static smooth modulation}
\Rightarrow
\text{deformed existing diagram}
}
\]

but

\[
\boxed{
\text{dynamical modulation}
\Rightarrow
\text{new dynamical system}.
}
\]

8. Distribution-shape correction

The infinite-\(N\) onset statement also needs precision.

For a smooth even distribution genuinely peaked at \(\omega=0\),

\[
g''(0)<0
\]

is the generic unimodal case.

A statement involving

\[
g''(0)>0
\]

describes a local minimum at the origin or a bimodal tendency rather than an ordinary smooth unimodal peak.

And when

\[
g''(0)=0,
\]

as in a sufficiently flat-topped distribution, the cubic amplitude term can vanish and higher-order analysis becomes necessary.

So distribution shape is itself part of the bifurcation architecture.

9. Bridge to the field clock

The Kuramoto triad is therefore a reduced synchronization comparator, not the complete D1 field clock.

It can answer:

\[
\text{How does coherence appear?}
\]

\[
\text{Where is the slip boundary?}
\]

\[
\text{How does coupling move the system between running and locked states?}
\]

It cannot by itself supply the gauge-link, holonomy, winding-sector, or real-time field dynamics needed for the larger field model.

Those are separate witnesses and separate dynamical obligations.

The full architecture should therefore remain:

\[
\boxed{
\text{phase dynamics}
+
\text{topological sector}
+
\text{winding}
+
\text{field dynamics}
+
\text{return}.
}
\]

Kuramoto is not one synchronization switch.

It is a family of mechanisms that create, destroy, deform, or destabilize clocks.

\[
\boxed{
\textbf{
Kuramoto is a stack of clock-creation and clock-destruction mechanisms.
}
}
\]
