# Machine-Readable Corpus

This repository is the public, source-controlled home for the individually reviewed machine-readable corpus.

## Current release boundary

The initial publication candidate contains five governing, impersonal research artifacts:

- OMNIBUS v7.77
- GQG v0.12
- Hidden Quotient Core v1.6
- Hidden Quotient Operational Addendum v0.7
- Return-Residual Stack Upgrade Manifest v1.1

The wider Drive inventory is not silently published. Files involving private people, or files whose public status remains uncertain, stay off GitHub pending an explicit per-file decision.

## Evidence boundary

Repository inclusion preserves the status declared by each source. It does not upgrade a theorem into an empirical finding, a framework into evidence, or a source pointer into corroboration.
